# Style bible

Complete this before placing map elements. Keep choices tied to the requested
scene and revise them only if the user changes the brief.

| Field | Decision |
| --- | --- |
| Use | battle map / exploration / scene |
| Focal event | first thing players should read |
| Primary and secondary zones | purpose and visual weight |
| Route | entrances, circulation and sight lines |
| Route states | each required route is open, blocked or gated, with a clear reason |
| Setting inputs | climate, culture, time of day: they set ground, planting, water's role and ambient |
| Art family | the one pack style the map is drawn in, its pack ids, and any named exception |
| Palette and mood | 2–4 material/light relationships |
| Density gradient | quiet, active and transition areas |
| Coverage and emphasis | broad playable coverage; dominant, supporting and quiet zones |
| Region plan | every exterior zone and interior room, each marked hero, supporting or quiet |
| Room program | the rooms the building's class needs, beyond the ones the brief names |
| Dressing layers | per room: anchor, secondary pieces, surface dressing, wall dressing |
| Playability | token scale, cover, doors, VTT semantics |
| Asset searches | category plus descriptive terms |
| Completion checks | visible evidence before finish |
