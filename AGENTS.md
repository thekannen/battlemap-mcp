# Contributor instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing code. Run the offline gate before claiming completion. Test map mutations only in a disposable editor session on an explicitly named scratch map. Never use a user's working map for tests.

User docs live at https://knownframe.com/battlemap-mcp/docs/, which the maintainer updates. If a change alters what users see or do, say in the pull request which page there needs a matching update.

Keep package, plugin, and bridge versions aligned. Restart Dungeondraft after changing the bridge and confirm its loaded identity before live testing. Do not change permissions on Dungeondraft-owned folders.

Do not post issue, pull request, or review comments on behalf of the owner without explicit authorization. Draft proposed replies instead. Publication, signing, and repository visibility changes require separate authorization.
