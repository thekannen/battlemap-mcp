battlemap-mcp companion

Extract the entire archive into a permanent user-owned folder. Keep the executable
and _internal folder together. No Python, uv, or PATH changes are required.

Windows: double-click Connect Codex.cmd or Connect Claude Code.cmd.
The named Connect file installs bundled skills and registers this companion for
that client. Existing skills are preserved. Then double-click Check connection.cmd.
Wait for "Ready", then fully quit and reopen your AI client.
Do not double-click battlemap-mcp.exe itself: your AI client runs it for you.

macOS: the same Connect and Check connection files end in .command.
Terminal alternative (also for Linux installation):
  ./battlemap-mcp setup --client codex
  ./battlemap-mcp doctor --live --brief

If Codex automatic setup is unavailable, the Connect file shows the exact command
path to paste into Settings > MCP servers > Add server (STDIO, no arguments).
Claude Code needs its own command-line tool; this does not configure Claude chat.

Choose the client you use. Setup installs skills and registers this executable;
it does not install the mod or change Dungeondraft settings. Install the separate
matching mod ZIP. In Dungeondraft, Mods > Browse must select the folder
CONTAINING battlemap-mcp-bridge. Tick Battlemap MCP Bridge, click Accept, fully quit
and reopen Dungeondraft, then open a map.
Never register from a temporary build/download/extraction directory. If you move
or upgrade this folder, run the matching Connect file from its permanent location.
For Claude Code, if its entry points at an old location, first remove it:
  claude mcp remove --scope user battlemap
Then run setup --force --client claude-code. Keep the old companion until setup
succeeds. --force updates skills; it cannot overwrite Claude's existing entry.
Repeating Connect at the same path is harmless. Do not mix _internal files from
different versions. Keep the entire companion folder together when updating.
Linux has been validated on Ubuntu 24.04 under WSL2 only. Run the Linux editor
and AI client in the same Linux environment, and see the repository's Linux
installation guide for details.
